# Bing Webmaster Tools review, 19 October 2026

Property `https://camzify.com/`. Figures as Bing showed them on 19 Oct; performance is the
four weeks to 16 Oct.

## The numbers

- **Search:** 5 clicks, 167 impressions (Google, same weeks: about 22,000 impressions).
  Bing ranks the site at positions 2 to 10 for long-tail queries ("do all ip cameras support
  rtsp" 3.0, "patrol sequences" 3.0, "directional virtual tripwire" 2.5, "cloud vms with
  virtual patrolling" 1.5) and not at all for the head terms that carry Google's impressions
  (cloud vms, intelligent video analytics, cloud video surveillance, virtual patrol).
- **Copilot (AI Performance):** 81 citations, 13 pages cited. Top: www.camzify.com/supported-cameras
  (36), /platform (10), / (9), /ai-features/line-intrusion-detection (4). Several cited URLs are
  the www copies.
- **Index:** 153 URLs indexed (Site Explorer), against 279 in the sitemap. 2 warnings, 2 excluded.
- **Sitemaps:** three read successfully: /sitemap.xml, plus /sitemap_index.xml on both hosts
  (a WordPress-era address that now redirects to /sitemap.xml). 413 URLs discovered in all.
- **IndexNow:** working. 254 URLs submitted since 29 Sept, by .github/workflows/indexnow.yml.
- **Backlinks:** 4 referring domains, 19 pages: linkedin.com (14), deutics.com (3),
  techdirectory.sg (1), findglocal.com (1).
- **Recommendations report:** no data.

## What is wrong

1. **Too few sites link to camzify.com.** Four referring domains is the main reason Bing does
   not rank the site for competitive terms. Bing weighs links and domain authority more
   heavily than Google does, and the long-tail positions show the content itself is fine.
2. **Bing holds stale copies of some pages.** URL inspection, 19 Oct:
   - /guides/what-is-a-cloud-vms: "Not indexed as this page is a redirect" (last crawl 9 Oct).
     The live page answers 200 to Bing's user agent; Bing's own live test errored.
   - /guides/what-is-virtual-patrolling: indexed, but Bing's copy has no title, meta
     description or H1. The live page has all three.
   - /guides/what-is-intelligent-video-analytics: "alt attribute missing, 2 instances". The live
     page has alt text on every image.
   - Fine: /cloud-video-surveillance, /virtual-patrolling, /ai-features/camera-tampering-detection.
   The IndexNow workflow only submits URLs whose source changed in a release, so a page with a
   bad copy and no new edits is never resubmitted.
3. **www copies linger.** www.camzify.com redirects to camzify.com in one hop, but Copilot still
   cites www URLs, so Bing has not finished consolidating them.
4. **Heavy HTML.** Bing recorded the homepage at 566.8 KB. Measured 19 Oct: homepage 553 KB
   (243 KB of it the Next.js payload), guides and feature pages 190 to 270 KB. Not urgent, but
   worth confirming with Bing's Site Scan, which checks page size among other things.

## What was done

- `scripts/indexnow.mjs --all` resubmits every sitemap URL (279), and the IndexNow workflow can
  now be run by hand from GitHub (Actions, IndexNow, Run workflow) to do the same. Use it once
  now, and after any fix that changes many pages without changing their source.

## Next steps

1. **Resubmit everything once** via the workflow, then re-inspect the three pages above in a
   week.
2. **Request indexing in Bing** for /guides/what-is-a-cloud-vms (URL inspection, Request
   indexing), since its copy is the worst.
3. **Run Site Scan** in Bing Webmaster Tools (it crawls up to the limit you set and lists
   issues, page size included); the Recommendations report stays empty until a scan exists.
4. **Earn links**, US first. In order of effort: ask Nettbox (the Singapore partner) and other
   partners to link from their sites; complete company listings that carry a link (Crunchbase,
   G2, Capterra, SourceForge, Clutch); Bing Places for Business; guest articles or quotes in
   security trade press. Each new referring domain matters more on Bing than on Google.
5. **Re-check on 2 November**: index count, the three pages above, Copilot citations by page.
