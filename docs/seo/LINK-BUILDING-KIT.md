# Link-building kit

Why: Bing Webmaster Tools (19 Oct 2026, docs/seo/BING-2026-10-19.md) counts four sites linking
to camzify.com: linkedin.com, deutics.com, techdirectory.sg, findglocal.com. Bing ranks the
site for long-tail questions but not for any competitive term, and links are what it is
missing. Every fact below comes from lib/site-config.ts or a page on the site; keep it that
way when a listing asks for more. If a form wants something not here (headcount, founding
date, customer names, certifications), the answer is the business's to give, not an estimate.

### Descriptions

**Tagline (under 60 characters):**
Cloud video surveillance and AI patrols on your cameras

**Short (under 160 characters):**
Camzify is a cloud video management system that adds AI detections, scheduled virtual patrol rounds and cloud recording to the IP cameras you already own.

**Long (about 120 words):**
Camzify is an AI-powered cloud video management system for the cameras a business already
owns. Any IP camera that offers RTSP or ONVIF connects, along with RTMP and HTTPS streams,
and cameras on a private network connect through the Camzify Connector with no port
forwarding. Each camera records to the cloud continuously or on a schedule, with retention
set per camera. On top of recording, Camzify runs 23 AI detections, from intrusion and
loitering to PPE and fire and smoke, and alerts the assigned person within seconds of a
confirmed detection. Scheduled virtual patrol rounds check a list at every camera and file a
timestamped report with a compliance percentage. Every site is managed from one console.
Pricing starts from $5 per camera per month, quoted per site.

**Features (for checkbox lists):** live streaming; cloud recording and backup; retention per
camera; 23 AI detections (intrusion, line crossing, loitering, tailgating, PPE, fire and
smoke, slip and fall, weapons, camera tampering and more); alerts by email, SMS, WhatsApp or
push; scheduled virtual patrol rounds with compliance reports; multi-site management; user
and permission management; forensic video search; browser-based access on desktop and
phone. Native mobile apps are in development, so do not tick "iOS app" or "Android app".

## 4. Where to list, in order

| Listing | Link type | Notes |
|---|---|---|
| Bing Places for Business (bingplaces.com) | Business profile | Import from a Google Business Profile if one exists, otherwise create. Same name, address and phone as above, character for character. |
| Crunchbase | Company profile | Free organization profile; website and social links. |
| G2 | Product profile | Free listing; pick the categories that match "video surveillance" and "video analytics". Reviews from real customers help most. |
| Capterra (and with it GetApp, Software Advice) | Product profile | Free basic listing; one submission covers all three Gartner sites. |
| SourceForge | Product profile | Free; it already ranks for "blue iris alternatives". |
| Clutch | Company profile | Free; suits the services side if Camzify is also offered with installation through partners. |
| Security trade press (US) | Articles, quotes | Contribute expert answers or a byline; worth more than any directory. |

Use the exact name, address and phone from section 3 everywhere. A listing that spells the
address differently weakens the match between them.
